Used RTX 3090 prices might be about to go up.

An open source project just unlocked the full FP16/BF16 tensor rate on RTX 30 series cards. Same card adn same power limit but up to about 80% more matrix throughput in reported benchmarks.

The trick is simple. A kernel module flips the speed registers at boot, before NVIDIA’s driver takes over. The stock driver stays as it is. Also you can most probably put it in the grub entry to avoid the hassle for each time boot. Oh and currently its for linux only.

I run local LLMs and image models on a 3090, so this one caught my attention. Prefill and diffusion get the boost. Decode stays memory bound, so don’t expect double tokens per second. I wonder how the modded 48gb 3090 would perform.

Worth a look: https://github.com/Zagitta/gpu-unlock
